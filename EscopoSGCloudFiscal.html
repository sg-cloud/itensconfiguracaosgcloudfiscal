#1623802 ALTERACOES NO CADASTRO DE PRODUTO PARA INCLUIR O VALOR DE IBS E CBS NO PRECO DE VENDA. SGCLOUD naiane Tarefa 04/09/26 new 13.0 1

ONDE:

- Loja > Cadastros > Produtos > Valores

O QUE OCORRE:

- Como em 2027 o IBS e o CBS serão impostos por fora, somados ao total da nota, necessário incluir esses impostos no preço de venda dos produtos.

O QUE FAZER:

- Criar 3 novos campos antes do campo &apos;Preço de venda&apos;: &apos;Preço sem IBS/CBS&apos;, &apos;Valor IBS&apos; e &apos;Valor CBS&apos;.

- Para encontrar os valores que irão nos novos campos, será necessário efetuar um cálculo reverso no preço de venda atual, para descobrir o preço base a ser apresentado nos impressos e nas telas, juntamente com o IBS e CBS por fora, sendo a soma do preço base + ibs e cbs o preço de venda final.

Exemplo:

- Encontrar preço de venda com IBS e CBS:

Custo = 100,00

ICMS = 12%

Custo s/ ICMS = 100,00 × (1 - 12%) = 88,00

Margem = 30%

Fator = 1 - ICMS venda - Margem

Fator = 1 - 0,12 - 0,30 = 0,5800

Preço base = Custo sem ICMS / Margem

Preço base = 88,00 / 0,5800 = 151,72

A base de cálculo do IBS e CBS retira o valor de ICMS:

Base IBS/CBS = Preço base x (1 - ICMS de venda)

Base IBS/CBS = 151,72 × (1 ? 0,12) = 133,51

Para fins de exemplo do cálculo será considerada a alíquota de 4% de IBS e 4% de CBS.

Valor IBS = Base IBS/CBS x Aliquota = 133,52 × 4% = 5,34

Valor CBS = Base IBS/CBS x Aliquota= 133,52 × 4% = 5,34

Preço Final = Preço base + IBS + CBS

Preço final = 151,72 + 5,34 + 5,34 = 162,40

- Extrair IBS e CBS do Preço de venda já gravado

Preço total gravado = R$ 170,00

ICMS = 12%

IBS = 4%

CBS = 4%

Total de IBS + CBS = 8%

Como o preço de R$ 170,00 já contém IBS e CBS, primeiro precisamos removê-los.

Divisor=1+(1?ICMS)×(IBS+CBS)

1+(1?0,12)×(0,04+0,04) = 1,0704

Preço base sem IBS/CBS = 170,00÷1,0704=158,82

Retirar o ICMS do Preço base

158,82×12%=19,06

Encontrar a Base do IBS e CBS

158,82?19,06=139,76

Valor IBS

139,76×4%=5,59

Valor CBS

139,76×4%=5,59

Preço de venda = Preço base + IBS + CBS

158,82 + 5,59 + 5,59 = 170,00

- Usar como base o cálculo do link - http://ajudaia.sgsistemas.com.br/simulador/

- Verificar a regra na tabela START para apresentar os novos valores:

NOTA_TEC= 2025.002

DESCRICAO = HOMOLOGACAO/PRODUCAO.IBSCBSNOTOTAL

Caso regra não esteja ativa, será mantido o cálculo atual (sem calcular para descobrir o valor de IBS e CBS).

- Para efetuar o cálculo utilizar do Grupo de imposto IBS/CBS sempre a regra de Consumidor final para o meu próprio estado e município.
